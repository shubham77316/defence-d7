# Defence Sovereign Systems — Standalone Frontend

This is the pure, standalone frontend of the **Defence / Skywardens** website built with Next.js (App Router), Tailwind CSS, Framer Motion, and Three.js.

## 🚀 How to Run Locally

1. Install dependencies:
```bash
npm install

```

2. Run development server:
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## 📦 How to Build for Production


```bash
npm run build
npm run start
```

## 🌐 Deploy to Vercel (1-Click Deployment)

1. Push this folder to a GitHub repository (e.g. `defence-frontend`).
2. Go to [https://vercel.com](https://vercel.com) and click **"Add New..."** -> **"Project"**.
3. Import the repository.
4. Keep all default settings:
   - Framework Preset: `Next.js`
   - Root Directory: `./`
5. Click **"Deploy"**!
